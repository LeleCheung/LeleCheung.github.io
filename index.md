## Selected Projects

- **Mosaic: Microarchitectural Characterization of LLM Inference on AICPUs:** Constructed Mosaic-Dataset by profiling 340 microarchitectural events across representative workloads selected from 107 models and 1,108 tasks. Phase-specific models and attribution analysis identify key performance factors and guide runtime configuration, achieving 1.23x end-to-end speedup over the llama.cpp default configuration while reducing exploration cost by 320x relative to brute-force search.
- **HG-KDA: Hardware-Grounded Kernel Design Agent (WIP):** Designed a cross-platform kernel optimization framework combining static hardware knowledge, dynamic profiling, evidence fusion, bottleneck diagnosis, and structured kernel action plans.
